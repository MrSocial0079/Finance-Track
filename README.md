# 💰 Fintrack – Personal Finance Tracker

Fintrack is a web-based personal finance tracker built using **Streamlit**, **Firebase Firestore**, and **FastAPI**. Designed to help users monitor their daily expenses, visualize spending trends, and learn about personal finance, Fintrack makes budgeting intuitive, educational, and even fun!

## 🚀 Features

### ✅ Basic Functions
- **Google Sign-In Authentication** (via Firebase)
- **Add, view, update, and delete** transactions
- **Filter transactions** by category and date
- **Visual pie chart** showing total spending by category
- **Real-time database sync** using Firebase Firestore

### 🧠 Advanced Features
- **AI Financial Literacy Assistant**  
  Ask personal finance questions (e.g., "What is a credit score?") and get real-time answers powered by **Gemini API**.
  
- **🎯 Spin the Wheel Gamification**  
  A fun daily feature that gives users motivational finance tips, savings challenges, or rewards to encourage consistent use.
